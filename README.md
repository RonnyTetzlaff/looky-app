# Looky – Webseite

Support- und Datenschutzseite der iPhone-App **Looky**, bereitgestellt über GitHub Pages.

- `index.html` – Kurzbeschreibung, Hilfe & Kontakt (Support-URL)
- `datenschutz.html` – Datenschutzerklärung (Datenschutz-URL im App Store)

Der Code der App liegt in einem eigenen, privaten Repository.
